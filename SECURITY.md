# Security Policy

KubeRescue is an early MVP for development and staging clusters.

## Supported Versions

Only the latest code on `main` is supported.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to the project maintainer.
Do not open a public issue for sensitive security reports.

## Current Safety Limits

- No retry budget
- No cooldown window
- No policy engine
- No audit sink beyond stdout

Do not run this project unattended in production clusters yet.
